## Descripción del proyecto

JHEMS JOB es un sistema web de gestión empresarial diseñado para centralizar y optimizar procesos comerciales y administrativos.

Permite gestionar ventas, pagos, inventario, usuarios, reportes y flujos operativos desde una plataforma centralizada.

**Sistema web:** https://jhemsjobsistemas.com/login

## Tecnologías utilizadas

- Backend: Node.js y Express.js
- Base de datos: MySQL
- Lenguaje: JavaScript
- Arquitectura: Aplicación web con lógica de negocio del lado del servidor
- Infraestructura: Servicios de alojamiento en la nube

## Módulos principales

### Gestión de ventas
- Registro y seguimiento de ventas.
- Consulta de detalles y estados.
- Administración del flujo comercial.

### Gestión de pagos
- Registro y control de pagos.
- Seguimiento de saldos pendientes.
- Validaciones y redistribución de importes.

### Inventario
- Gestión de productos y movimientos.
- Control de operaciones de almacén.

### Usuarios y roles
- Administración de permisos por roles.
- Separación de responsabilidades entre áreas.

### Reportes y dashboard
- Visualización de información operativa.
- Consultas y reportes administrativos.

### Automatización
- Integración con mensajes rápidos de WhatsApp.
- Procesamiento de flujos operativos.
- Tareas programadas y respaldos.

## Arquitectura general

El sistema utiliza Node.js y Express para procesar las solicitudes, aplicar las reglas de negocio y comunicarse con MySQL.

La plataforma integra distintos módulos administrativos bajo un esquema de usuarios y permisos.
